# Tools to bring

**For students. Read before week 1. About 5 minutes.**

Every session is a working session, so you need your own AI tool on your own laptop. You do not need to buy everything. You need **at least one tool that works for the next few weeks**, and a second kind by the prototype weeks.

## What you need, and when

| Kind | What it is for | Needed from | Examples (recommended, not required) |
|---|---|---|---|
| **AI chat tool** | You write, it replies. Used in every week: planning questions, synthesising quotes, drafting options, preparing tests | **Week 1** | **Claude** |
| **AI coding tool** | Reads and writes files in your project folder and builds working prototypes | **Week 6** (the first prototype) | **Cursor**, **Codex** |

Any equivalent tool is fine. The names above are examples, not a list you must follow.

## How to choose
1. **Your company's rules first.** If you work somewhere, check which AI tools are allowed (see the data-safety part of week 1). If none are allowed, tell the instructor: you will use the course case for the in-class steps.
2. **It must accept a file.** You will attach `product-and-users.md` and other files. A tool that only takes typed text will slow you down.
3. **Check what happens to your data.** Read the tool's data controls before you paste anything real. Settings and plans change.
4. **It should run on the laptop you bring to class.** Try it there, not on another device.

## Cost
Some tools or features need a paid plan, and plans and prices change. Check the current options before the course starts. Do not assume the free version is enough for the prototype weeks. Bring one tool you are comfortable paying for or already have, rather than trying several.

## A 5-minute test before week 1
1. Open your tool and create a short text file on your laptop with three lines about any product.
2. Attach the file and ask: "Use only this file. List three things you would need to know that are NOT in it. If unclear, say 'unknown'."
3. If it reads the file and answers, you are ready. If you cannot attach a file, or it makes things up, tell the instructor before class.

## For the prototype weeks (week 6 onwards)
Before week 6, check that your AI coding tool can open a folder on your laptop and read the files in it. The instructor will give you a starter folder. Make sure the tool you bring can use it.

*Examples change quickly. The instructor will confirm the current recommended tools before the course starts.*
