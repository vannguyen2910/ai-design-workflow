# Course project: Delivery App (fictional)

**Everything in this folder is invented.** No real company, person, review or number.

Use it when:
- your company bans AI tools, or your own project is too sensitive for class;
- you missed a week and need to catch up;
- you want a safe project to practise on.

| File | Used in | Notes |
|---|---|---|
| `case-card.md` | Week 1 demo and fallback project | One page |
| `po-case-pack.md` | Retired, not used in class | For the student who has no PO to talk to. **The PO-only section is for the person playing the PO** |
| `source-notes.md` | Retired for class use: the old 24 one-line notes. Kept only for `blind-synthesis` history and `source-notes-answer-key.md` | 24 fictional one-line source notes with IDs, from three kinds of source. Replaced by `evidence/` in Week 2 and Week 3 (2026-11-20) |
| `raw/I01.txt`, `raw/I02.txt` | Week 2, Practice 2, Ingest data | Two fictional anonymised interview transcripts. Each turn starts with its number so a quote can point to it |
| `evidence/I01.md`, `I02.md`, `tags.md` | Week 3, Practice 3, Synthesis | Ten evidence notes (RET-01 to RET-10) written from the two transcripts, one file per interview with one `##` entry per note: observation title, fields, verbatim quotes with source and turn. `tags.md` is the fixed two-level tag list the notes use |
| `check-clean-instruction.md` | Week 2, Practice 2, Ingest data | Instruction for an AI coding tool to write a script that compares a cleaned transcript with the anonymised draft, turn by turn |
| `transcript-before-clean/I01-before-clean.txt`, `names-to-check.txt` | Week 2, Practice 2, Ingest data | The anonymised draft of interview I01 before cleaning (timestamps and fillers still in), and a sample list of names the check must not find |
| `check-evidence-instruction.md` | Week 3, Practice 3, Synthesis | Instruction for an AI coding tool to write a script that checks every quote against the raw transcript. Replaces `check-quotes-instruction.md` |
| `insight-set.md` | Week 3 | Nine fictional insights with insight IDs, evidence note IDs and strength (rebuilt on the ten evidence notes, 2026-11-20); the input for persona, journey map and opportunity |
| `persona-ai-draft.md` | Week 3 activity | A six-line persona an AI might write; some lines have an insight behind them, some do not. Answer key inside, instructor only |
| `competitors/` | Week 2 demo | Three fictional competitor pages |
| `brief-notes-plain.txt` | Week 2, Break the brief | 10 dòng brief của business dạng `ID | text` (B01 đến B10), có giả định ngầm và hai chỗ mâu thuẫn |
| `break-the-brief-moves.md` | Week 2, Break the brief | Prompt và kết quả đã lưu của bốn cách dùng AI trên brief mẫu, kèm giới hạn |
| `insights-plain.txt`, `persona-draft-plain.txt`, `journey-map-draft.md`, `opportunities-draft-plain.txt` | Week 3, cách dùng AI | Chín insight có ID (căn cứ là evidence note RET-xx), sáu dòng persona nháp, một journey map nháp và năm opportunity nháp, dạng `ID | text`, cho bảy cách dùng AI |
| `evidence-notes-plain.txt` | Week 3, Cách dùng AI 4 | 10 evidence note gộp thành mỗi note một dòng |
| `define-moves.md` | Week 3, cách dùng AI | Prompt và kết quả đã lưu của sáu cách dùng AI (persona, journey map, opportunity), kèm giới hạn |
| `source-notes-answer-key.md` | Instructor only | The intended themes, the traps, and what a good answer looks like. **Do not share with students before the exercise** |
