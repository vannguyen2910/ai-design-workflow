# Accessibility rules

*The requirements the design must meet. Edit to match your company's standard. If you have none, use these as a baseline (WCAG 2.2 AA).*

- Text contrast at least 4.5:1 (3:1 for large text and for interface parts such as input borders)
- Everything works with a keyboard, in a logical order, and the focus is always visible
- Every input has a visible label; errors say what went wrong and how to fix it
- Touch targets at least 44 by 44 px where possible (never below 24 by 24)
- Meaning is never carried by colour alone
- Images that carry meaning have a text alternative
