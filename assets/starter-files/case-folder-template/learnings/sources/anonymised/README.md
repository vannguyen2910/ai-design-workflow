# anonymised

Chỉ bản **đã ẩn danh** mới nằm ở đây. AI tool đọc được folder này.

- Mỗi nguồn một file hoặc một folder, tên rõ ràng, ví dụ `interview-01.md`, `reviews-store-2026-10.md`, `competitor-a-pricing-2026-10.png`.
- Mỗi quote có một ID (R01, I01-01 ...) và giữ nguyên văn. Không viết lại cho gọn.
- Ghi ngày thu thập, và lưu bản sao thay vì chỉ lưu link, vì trang web đổi.
- File ở đây là bằng chứng. Phần phân tích viết ở working file, không viết đè lên dữ liệu gốc.
- Chưa chắc một file đã sạch thì để nó ở `_raw-private/`.
