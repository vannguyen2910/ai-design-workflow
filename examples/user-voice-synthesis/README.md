# Example: User-Voice Synthesis

Second worked example of the activity flow standard (`../../learning/method.md` Part 1). Main in-class activity of the Discover lesson.

| Part | Where |
|---|---|
| step cards | `step-cards.md` (this folder) |
| Hub page | Evidence page of `../../assets/templates/hub/` ("What users said") |

Pattern: A Investigate · 8 steps · 3 gates (A right voices, B word for word and traceable, C weighed, not counted). Pair it with the competitor analysis (`../competitor-analysis/`) so every evidence pack covers both what others do and what users say or do.
