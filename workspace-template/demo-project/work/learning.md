*After launch. Travel Buddy is an academic practice project and has not been released, so there are no real measurements. This page says so clearly instead of leaving it empty.*

## What we shipped
Not released. There is only a prototype and one simulated usability test round.

## What the numbers said
No measured results yet. All five metrics have a target but no verdict yet: the first three (task completion, ease score, usability score) can only be checked with a test with real people, and the other two (time to first tip, sign-up rate) need analytics after launch.

## What we learned
- The simulated test round only gives a signal about usability, it does not replace a real test.

## Opportunities to revisit
- Planning: ranked first based on a small survey; needs to be checked again with real users once there is behavioural data.
- Keeping a record of the trip: unclear whether it is behaviour or a wish; research journaling before building it as a core feature.

## What changes next
Run a test round with real people for the first three design hypotheses, then record the result and verdict on each metric.
