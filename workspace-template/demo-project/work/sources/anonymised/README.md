# anonymised

Only the **anonymised** version belongs here. The AI tool can read this folder.

- One file or one folder per source, with a clear name, for example `interview-01.md`, `reviews-store-2026-10.md`, `competitor-a-pricing-2026-10.png`.
- Each quote has an ID (R01, I01-01 ...) and stays verbatim. Do not rewrite it to make it shorter.
- Record the collection date, and save a copy instead of only saving the link, because web pages change.
- Files here are evidence. Analysis goes in the working file; do not write over the original data.
- If you are not sure a file is clean, leave it in `_raw-private/`.
