*Define: decide which problem is worth solving. Method card: fill this in when you run the method.*

## When to use
The team keeps debating style and direction, or you need a shared yardstick.

## How
1. Collect the values that came up in research and strategy.
2. Write each principle as a short instruction with a 'so that'.
3. Add an example of what it means and what it rules out.
4. Share and agree; add them to Standards as checks.
