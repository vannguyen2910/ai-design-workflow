*Discover: understand the problem and people. Method card: fill this in when you run the method.*

## When to use
You already have a product or service, and want a fast, evidence-based view of its problems before you talk to users.

## How
1. Pick 3 to 5 key tasks a user does in the current product.
2. Walk through each task and check every screen against the 10 usability heuristics (see Standards).
3. Log each problem with a severity from 0 to 4.
4. Group problems by task and rank them.
