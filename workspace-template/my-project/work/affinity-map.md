## When to use
You have a pile of notes, quotes and observations from Discover.

## How
1. Put each observation on its own note with its source.
2. Group notes that belong together without naming the groups first.
3. Name each group with a sentence that says what is true, not a topic.
4. Count notes per group and mark the strongest themes.

## Output
| Theme (a sentence) | Notes | Sources | Strength |
|---|---|---|---|
|  |  |  |  |

## Ask the AI tool
> Group these anonymised observations into themes. Name each theme as a sentence, list the source IDs, and show how many sources support it. Propose first.
