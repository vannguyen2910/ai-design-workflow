## When to use
The flow is agreed and you want to check layout and content hierarchy.

## How
1. Pick the 5 to 8 screens that carry the flow.
2. Sketch layout and content priority, no visual styling.
3. Annotate each screen with the decision or solution it carries.
4. Review with the team and note open questions.
