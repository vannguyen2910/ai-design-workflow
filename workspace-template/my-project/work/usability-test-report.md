*Deliver: test, hand off and launch. Method card: fill this in when you run the method.*

## When to use
After a usability test, to turn observations into decisions.

## How
1. Record participants and method (real vs simulated).
2. Report task success, time and errors against the baseline.
3. List findings with severity and the decision they affect.
4. State what changes because of the test.

## Output
| Task | Success rate | Time | Errors | Finding (severity) |
|---|---|---|---|---|
|  |  |  |  |  |

## Ask the AI tool
> From these anonymised test notes write a report: per task results, findings with severity 0 to 4, and which decision each affects. Propose findings first.
