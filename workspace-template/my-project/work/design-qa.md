*Deliver: test, hand off and launch. Method card: fill this in when you run the method.*

## When to use
Before launch, when a build is available.

## How
1. Compare each key screen with the design.
2. Check spacing, states, copy and responsive behaviour.
3. Check accessibility rules from Context.
4. Log each difference with severity and an owner.
