*Develop: explore and shape possible solutions. Method card: fill this in when you run the method.*

## When to use
A How-might-we question is agreed and you want options, not the first idea.

## How
1. Restate the How-might-we.
2. Set a timer; each person writes or sketches 8 ideas (Crazy 8s) or uses brainwriting.
3. Cluster similar ideas and add wild ones deliberately.
4. Dot-vote to pick 2 or 3 directions and note why the rest were parked.
