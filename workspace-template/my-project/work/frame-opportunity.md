*Define: decide which problem is worth solving. Method card: fill this in when you run the method.*

## When to use
You have themes and need to decide which problem is worth solving.

## How
1. Write the need as: [user] needs [outcome] because [insight].
2. Add evidence: sources and how many people.
3. Write 1 to 3 How-might-we questions that do not contain a solution.
4. Record the opportunity as an item (O1, O2...) with a rank and a reason.

## Output
| User | Need | Because (insight) | Evidence | How might we... |
|---|---|---|---|---|
|  |  |  |  |  |

## Ask the AI tool
> From these themes, propose opportunities framed as 'user needs outcome because insight' with evidence and a How-might-we. Propose first; do not create items.
